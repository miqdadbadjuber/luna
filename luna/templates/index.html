How to Read the AI Clipper Interactive Canvas

Source Card (Left Side)

Shows the original YouTube video details before trimming, including its duration and thumbnail. This is the source node in the clip diagram.

Clip Cards (Right Side)

Each card represents one vertical video clip. It shows the model's viral score (for example, 94/100, an estimate and not a measurement), clip duration, hook quote, and an instant preview button.

System Configuration & Requirements

Luna needs these three things to process videos:

1. FFmpeg (for rendering and subtitles) installed automatically
$ ffmpeg -version

If FFmpeg is not on your PATH, Luna downloads a copy on first start. It merges audio and video, crops the frame and burns subtitles into the video.

2. API keys (clip ranking and transcription) .env file
$ OPENAI_API_KEY=your-api-key

Clip ranking uses any OpenAI-compatible provider, or Gemini. Videos without subtitles are transcribed with Groq (default), Gemini or local Faster-Whisper. Enter keys in Settings or in the .env file.

3. YouTube Cookies (Bypass Verifikasi Bot & Video Usia) cookies.txt
$ cookies.txt

Export YouTube cookies from your browser with the extension "Get cookies.txt LOCALLY", and save the file as cookies.txt in the Luna project root.

FAQ & Troubleshooting

Quick answers to common questions from new users:

Why do I see the warning "Invalid URL"?

Luna checks that the link is a valid URL using the https:// protocol and comes from YouTube (youtube.com / youtu.be), Instagram Reels, or TikTok. Check the link and try again.

What if my computer does not have a D:\ drive?

If the D: drive is unavailable, Luna automatically uses the output/ folder in the Luna installation directory.

YouTube memunculkan pesan "Sign in to confirm you're not a bot"?

This can happen when YouTube blocks your IP or requires account authentication. Install the Chrome/Edge extension Get cookies.txt LOCALLY, export your YouTube cookies to cookies.txt, and place the file in the Luna project root.

How do I get an OpenAI-compatible API key?

Create a key in your provider's dashboard, then enter the key, base URL and model in Settings or in the .env file.

When should I choose Face Tracking or Center Crop?

Select Face Tracking for podcasts or interviews focused on one speaker. It keeps the speaker centered in the vertical frame. Select Center Crop for vlogs with several moving people or screen recordings.
